# AutoMarket Canada — Vehicle Marketplace Platform

A responsive vehicle marketplace platform built with HTML, CSS, and JavaScript for showcasing cars, commercial vehicles, recreational vehicles, and heavy equipment within a clean and modern user interface.

This project demonstrates responsive frontend development, structured UI architecture, reusable component design, and marketplace-style layout systems for automotive and transportation platforms.

---

# Project Overview

AutoMarket Canada was designed as a vehicle marketplace interface focused on vehicle discovery, category-based browsing, and modern automotive presentation.

The platform includes:

- Vehicle Marketplace Homepage
- Search Interface
- Vehicle Category Showcase
- Automotive Listing Layout
- Responsive Marketplace Design
- Multi-Vehicle Type Display
- Marketplace Navigation Structure

The project demonstrates frontend engineering principles using pure HTML, CSS, and JavaScript with scalable UI organization.
